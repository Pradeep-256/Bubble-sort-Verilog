# Bubble-sort-Verilog
Hardware implementation of the Bubble Sort algorithm using a modular Datapath and FSM-based Controller in Verilog. The datapath performs comparison and swap operations, while the controller manages loop sequencing and control signals. Synthesizable RTL design suitable for FPGA/ASIC implementation and digital design learning.
